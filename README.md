# COVID-19 Global Impact Dashboard

## Project Overview
This project analyzes global COVID-19 cases and deaths using Python and Microsoft Power BI. It explores pandemic trends and presents key findings through data visualizations and an interactive dashboard.

## Objectives
- Analyze COVID-19 cases and deaths across locations.
- Explore daily new cases and deaths in India.
- Examine the case fatality rate and cases per million people.
- Create a dashboard to communicate key insights.

## Dataset
The project uses the Our World in Data COVID-19 dataset, which includes location, date, cases, deaths, and population-related indicators.

## Tools and Technologies
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Microsoft Power BI

## Project Workflow
1. Load the COVID-19 dataset.
2. Clean and preprocess the data.
3. Perform exploratory data analysis (EDA).
4. Create visualizations in Python.
5. Build a Power BI dashboard.
6. Summarize findings in a project report.

## Dashboard Highlights
- Total COVID-19 cases
- Total COVID-19 deaths
- Number of locations
- Latest data date
- Case and death trends
- Comparison across locations

## Conclusion
This project demonstrates the use of data cleaning, exploratory analysis, and visualization to understand COVID-19 trends and communicate findings effectively.
